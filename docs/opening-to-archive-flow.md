# 海岸到月面档案局：连续场景合同

## 海岸与月球

- 玩家意图：离开当下，找到可以回看的时间入口。
- 主要动作：靠近、按住、拖开、确认。
- 镜头变化：海岸远景推进至月球；月球被拖向右下，显露回测入口。
- 声音提示：海岸空间逐渐收窄，拖拽锁定与停泊分别由低频短音确认。
- 人的证据：无；这里只处理玩家自己的当下与模拟入口。
- 退出状态：玩家点击“开始回测”，进入不可逆的平行时间穿梭。

## 月球穿梭与白点

- 玩家意图：穿过没有发生的人生，抵达可以登记和审查的地方。
- 主要动作：确认后观看；输入在穿梭期间锁定。
- 镜头变化：星空旋转与分岔，月球向镜头靠近并像素溶解，三条时间流收束为中央白点；白点扩散至全屏。
- 声音提示：低频锁定、反向颗粒风、峰值吸入，白场出现时短暂归于安静。
- 人的证据：无；星流与分岔均为模拟视觉，不冒充真实经历。
- 退出状态：白场无黑帧地交给月面档案局。

## 月面档案局

- 玩家意图：走向审查席，留下回测所需的最少信息。
- 主要动作：前进、回答、落座。
- 镜头变化：全白缓慢退去，走廊和远处审查席显影；玩家立即可以按 `W / ↑` 前进。
- 声音提示：档案局机械低鸣接管空间；每个登记灯和回答分别给出克制反馈。
- 人的证据：电视中的平行人生影像明确标注为模拟；接入知乎资料后必须另行标注来源、日期与不确定性。
- 退出状态：完成登记与平行人生审查，档案门开启。

正式流程始终从 `/` 进入。档案局单场景调试入口为 `/?debug=archive`，不会出现在玩家流程中。
