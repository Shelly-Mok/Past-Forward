# 三幕验收与演示清单

## 自动验证

```sh
pnpm verify
pnpm exec playwright install chromium
pnpm test:e2e
```

测试使用隔离浏览器上下文和虚构测试输入，不读取操作者浏览器里的真实登记。默认自动启动／复用4174端口；如果此端口是其他项目，设置PLAYWRIGHT_PORT为另一个空闲端口。不要对真实用户存档运行清理脚本。

现有用例：

- `opening-to-archive.spec.ts`：根入口、回溯、五问、审查开门、主动步行、白场、第三幕继承35岁／18岁和种植，完整一条链路。
- `archive-door.spec.ts`：五问资料门禁、审查时间轴、开门后行走、白场、资料继承和窄屏。W防串字与问题导航规则另有单元测试；完整纠错／重置的UI流程按下方人工清单复核。
- `garden.spec.ts`：悬停、首次种植／重复触碰、年龄笔记、刷新、70岁以后、响应式、R中断，以及种到现年后的四颗小行星与裂隙四页（回溯／前进／前瞻／结束）。
- `flower-lifecycle.spec.ts`：盛开所需顺序帧、全部16帧到结籽、根部与透明检查、重放不重复写存档、取消不提交。

单元测试负责年龄解析与恢复、人物状态机、花帧时间轴、门时间轴、道路和移动输入门禁等。

## 人工演示顺序

| 步骤 | 操作 | 应看到的结果 |
| --- | --- | --- |
| 1 | 开根地址，不加scene参数 | 海岸可操作，不是产品说明页 |
| 2 | 向上滚动／↑，再按住月球拖一点后松开 | 靠近月球；未到阈值则回弹 |
| 3 | 拖到右下并点击开始回测 | 穿梭后白场进入档案局 |
| 4 | 按住W经过第一盏灯，不立即松开 | 问题弹出，角色停下，输入框不堆积W |
| 5 | 松开W，填写五问；中间试一次上一问 | 原答案可修改，不跳过尚未回答的问题 |
| 6 | 五问后E／空格／按钮落座 | 看完模拟审查才解锁开门 |
| 7 | 门开后再按W／↑ | 单一玩家沿平台走到门口，白屏转第三幕 |
| 8 | 查看登记资料和回溯年龄 | 现实年龄、原始目标、正在看年龄分开 |
| 9 | 悬停花，再点击 | 悬停只响应；点击才走近、蹲下、落种、生长 |
| 10 | 选择30—40岁 | 从种子到发芽、花苞、渐开、完整盛放 |
| 11 | 切40岁以后并种60—70岁 | 先成长盛放，再落瓣、结籽 |
| 12 | 重看生长中按R | 停在当前位置，原已种状态和笔记保留 |
| 13 | 新种植中按R，再刷新 | 不会把未完成章节存成已种 |
| 14 | 打开已种章节记录并切年龄 | 年龄各自记录；来源入口仍诚实显示待接入 |
| 15 | 种到现实年龄 | 进入月面三岔口，四颗像素小行星，不是发光黑圆 |
| 16 | 点回溯／前进／前瞻／结束 | 左侧零点小姐叙述，天上可点小行星；未接通接口时标明「演示内容 · 不是真实匹配结果」，接通后回填知乎原文并保留「不是命运定论」 |
| 16b | 本仓库执行 `pnpm zhihu:setup` / `pnpm zhihu:verify`，再打开 `/?zhihu=access` | 不依赖外层 zhihu-demo；鉴权有效时应看到真实搜索/热榜样本，密钥不出现在页面 |
| 17 | 顶栏「返回三岔口」 | 直接回到岔路，不停在裂隙内一层 |
| 18 | 390px竖屏／低动态设置 | 没有横向溢出，按钮可操作，场景与UI分别排布 |

第二幕“重置到入口”和门后R会清本次第二幕登记；第三幕R是保留资料的中断。测试这两种行为时不要混为一谈。

## 视觉与声音检查

至少查看：首个可操作画面、月球拖拽中、档案回答、白场交接、花朵发芽／开花／落瓣、动作恢复；桌面与窄屏都要截图。世界应占主体，主角只出现一次，文字不烧录在背景，根部不漂移，界面按钮不挡花。

音效需要额外人工试听：浏览器允许声音后，检查脚步、落种和完成反馈是否对应动作，切页和阅读时是否安静。自动测试与截图不能代替主观听感。
