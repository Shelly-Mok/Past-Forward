# 第四幕相遇修订 · 2026-09-14

本轮修复了人物从舱外斜飞的路线：原先以人物自身尺寸为单位进行 CSS 平移，无法与飞船门槛和舷梯一致。现在使用背景图的 1672×941 坐标，在桌面和手机裁切后共同映射舱门、人物与步行路线。

- 舱门：原图局部纹理组成两块滑动门板；门洞裁切内景与舱内角色，门框始终在前。
- 出舱：门板打开、人物在门内显露、跨门槛、下台阶、沿月面步行、站定；约 5.15 秒，可跳过。
- 步行：复用现有 07–12 六帧。站立复用 09 帧，短暂回望复用 01 帧。
- 站位：两个角色最终脚底同高，相向站在月面前景。
- 平行自我：由脚部重构，稳定后保留冷青半透明轮廓、扫描纹理和低频透明度变化。
- 动作：呼吸、换重心、点头、回望、倾听；轻触人物有回应；输入和模型等待联动发言姿态。不产生额外玩家发言。
- 气泡：按文字撑开，圆角矩形、短尾巴；玩家暖金、另一个我冷青。最新的两方对白分别绑定人物头部，尾巴与人物水平中心对齐，尾巴尖端距可见头顶约 10px。短句收窄、长句向上展开。
- 空间：桌面两人相向站于画面约 43% / 60% 处，气泡向各自外侧展开，避免靠拉远人物来容纳文字。手机左右各最多 43% 宽度，气泡底部与人物头部共用坐标计算，人物与输入区不重叠。
- 历史：常态只显示双方最新一句；右上角“回看对话”可查看完整交替记录，再点击“回到人物对话”恢复现场气泡。长篇回复保留全部内容，可触摸或键盘阅读，不截断正文。
- 手机：移动背景裁切，使舱门和舷梯可见；输入区与底部导航分开。
- 动态偏好：减少动态时直接进入站定状态；场景退出取消帧循环；后台暂停登场推进。

业务接口及上下文字段保持原状；新增异步回复代次检查，防止离开场景后的迟到响应重新打开对话。
