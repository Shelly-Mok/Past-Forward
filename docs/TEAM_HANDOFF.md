# 队友交接总册：第一幕、第二幕、第三幕

版本：2026-09-03，含花朵16帧连续生长。以本册、INTEGRATION和现有代码为当前基线；早期设计稿中尚未落地的内容不能视为已实现。

## 1. 我们在做什么

玩家带着自己的现实资料和“想回到什么时候”的愿望，从海边进入月面档案局，再在月面种下一段岁月。花代表章节，时间线代表具体年龄，零点小姐提供引导，内容服务未来提供时代背景、人生问题、相近经历和选择后的分支。

已完成的是可操作的三幕前端与本机保存。队友负责的视频所述核心模型尚未接入；本册不对视频未核实的算法细节作猜测。优先接通一个完整人生分支，验证玩法，再扩展全部人生内容。

```text
第一幕 / 海边
  向上滚动靠近月球 → 按住月球向右下拖 → 开始回测
  → 穿梭、分岔、白点汇聚
第二幕 / 月面档案局
  W/↑走到各登记灯 → 五问 → 落座 → 模拟人生审查
  → 解锁 → 门开启 → 玩家主动走到正门
  → 全白过渡（携带第二幕登记资料）
第三幕 / 月面人生花园
  定位回溯年龄 → 悬停章节 → 点击走近播种
  → 种子逐帧生长到章节形态 → 具体年龄 → 时间档案／笔记
  → 后续接入：问题、选择、来源、相近人生及分支结果
```

## 2. 第一幕：海边、月球与穿梭

### 玩家如何操作

1. 首页直接是黑白海岸，不经过介绍页。世界包含海面、远处月球和原角色。
2. 向上滚动靠近月球；也可用↑／PageUp推进，↓／PageDown后退。海岸逐渐退出，星空显露。
3. 文案序列结束后，出现“按住月球，拖向右下方”。这是指针拖动，不是按W走路。
4. 拖动不足会回弹；达到停泊阈值后月球停在入口旁。键盘聚焦月球后Enter／空格是等价确认入口。
5. “开始回测”变为可用，点击后锁定穿梭输入。正常穿梭时间轴6.8秒，经过回返、加速、分岔、穿越和到达；低动态模式缩短。
6. 白点变成白场，档案局在白场下显现；不会额外跳转到产品说明页面。

### 实现与不能破坏的细节

- `src/main.ts`：海岸画布、月球拖动、文案节拍、三幕调度。
- `src/game/input/moonDrag.ts`：拖拽投影和释放判断。
- `src/game/transition/warpTimeline.ts`：穿梭时间轴；`src/render/createWarpField.ts`：空间视觉。
- 开始回测前可回弹，开始穿梭后不重复触发。后台暂停相关计时。
- 普通环境动效克制；强运动只用于回溯与场景转换。第一幕的月球与第三幕天空的地球不是同一显示对象。

## 3. 第二幕：五问登记、审查与开门

### 空间和五问

W／↑或“按住向前”沿既定道路行走。经过尚未回答的检查点才弹出问题，移动暂停；右下回答框可键入或选快捷回答，Enter／“记录”确认。

| 序号 | 位置／路线进度 | 字段 | 当前问题 | 回答方式 |
| --- | --- | --- | --- | --- |
| 1 | 左侧第一盏灯，14% | `age` | 先告诉我，你现在几岁？ | 当前登记校验为10—100岁 |
| 2 | 右侧第二盏灯，30% | `gender` | 你如何描述自己的性别？ | 自由输入；男／女／非二元／不透露 |
| 3 | 左侧第二盏灯，47% | `family` | 你现在的家庭情况是什么样？ | 只需会影响选择的关系与责任 |
| 4 | 右侧第四盏灯，70% | `status` | 你现在处于怎样的学习或就业状态？ | 自由输入；上班／学生／自由职业／创业／待业 |
| 5 | 审查席，100% | `rewind` | 你想回到哪一年，或人生的哪个阶段？ | 年龄、年份或阶段原话，例如18岁／2020年／毕业前 |

这是现实登记。家庭和就业不是历史年表，不能自动当成18岁时的状态。每条回答上限80字符；空回答不能提交，性别可以明确填“不透露”。UI中的0—10岁章节是回看阶段，不等于允许0岁作为第二幕当前登记年龄。

### 输入保护、纠错与重置

- 弹框出现时，清空前进状态，并记住尚未松开的移动键。原先一直按住W产生的重复事件不会写进回答框；松开后可以正常输入文字。
- “上一问”：第一问禁用；其他问题可退回上一检查点，加载已有答案修改。后续已有答案仍保留，不无故清空。
- “重置到入口”：明确重启**这次第二幕登记**，清空第二幕内存和会话资料，回入口。不是第三幕的保留记录式R操作。
- 第二幕进入/刷新调试入口会调用新的登记流程；不能把sessionStorage理解为断点续走系统。

### 从审查席到第三幕

1. 五问完成后到ready状态，E／空格或前进按钮进入落座和审查。
2. 当前审查是标注为模拟的像素人生影片；没有真实人物数据和个性化模型接入。不能因用户填了年龄就宣称影片是其真实或预测人生。
3. 正常审查8.8秒、解锁1.05秒、开门5.6秒。此交付保留现有门版本，**不在交接整理中重做门**。当前门时间轴最大角75°，不是此前概念讨论中的90°；以现行代码为准。
4. 门打开以后人物不会直接复制到门口。玩家继续按W／↑或前进按钮，从座位沿平台走向正门；只绘制一个实时玩家。
5. 引导文案：“门已经打开了。准备好以后，就往前走吧。”配合“不用害怕 · 你只是去看看另一种可能”。
6. 到门口冻结末帧，渐入全白950ms，白场至少550ms，约1150ms显露第三幕；低动态模式更短。素材加载有超时保护，加载失败应显示提示而不是无限等待。
7. 原五项资料通过事件直接交给花园，不识别截图、不要求玩家重填。

第二幕门开启后的R重新进入会回到第二幕入口并清空本次登记。**第三幕R只取消当前动作／返回画面，保存规则不同**，不要把二者写成同一逻辑。

## 4. 第三幕：月面人生花园

### 布局

- 左上地球：玩家已经站在月球上，天空中不再画另一个月亮。
- 右侧档案舱、同一位主角；背景不烧录玩家，避免重复人物。
- 左侧零点小姐：现实年龄、回看年龄、当前提示和主要动作。
- 地面四个固定花朵交互位置。通过“40岁以后的时光／回看0—40岁”切换所承载章节，不要求70岁以后挤在同一屏。
- 底部时间线是**当前章节的具体年龄**，不是一个章节只有一个年份；左右键和屏幕箭头均可操作。
- 上方“同代·相近选择／同代·不同取舍／跨代·相似困境”是内容接入入口，目前明确待接入，不展示假头像、假匹配分数或假原话。

### 章节、年龄与花形

| 章节索引 | 年龄范围 | 最终花形 | 从16帧中的哪帧停下 |
| --- | --- | --- | --- |
| 0 | 0—10 | 种子 | 1 |
| 1 | 10—20 | 含苞 | 6 |
| 2 | 20—30 | 微开／待放 | 8 |
| 3 | 30—40 | 完全盛放 | 11 |
| 4 | 40—50 | 初落 | 13 |
| 5 | 50—60 | 渐落 | 14 |
| 6 | 60—70 | 结籽 | 16 |
| 7 | 70岁以后 | 延续，保持籽形 | 16 |

实际归属按左闭右开处理：10岁进10—20章，30岁进30—40章，70岁进延续章。延续章可选70、75、80、90、100岁。其他章默认节点为起点、+2、+5、+7、+10；+10是进入下一章的边界节点。明确的回溯年龄或当前查看年龄会补进所在章，例如18或83，不会被强制取整为20或80。

花形是项目的视觉隐喻，不代表年龄价值、健康衰退或寿命预测。晚于现实年龄的节点显示探索语义。

### 悬停、种植、人物和完整生长

1. 悬停：只改变光环、提示和人物朝向，不写存档、不播种。
2. 首次点击：人物转向 → 沿舱前可走地面走近 → 蹲下 → 播种 → 起身 → 在旁边观察生长。此时其他年龄动作锁定，防止同时种几朵或角色重复。
3. 生长始终从种子开始。比如30—40岁会经过破壳、发芽、长叶、结苞、含苞、微开、半开，最后全开；不是直接放大一朵成品花。
4. 40岁之后的花也先长到盛开，再经过低垂、落瓣与结籽，按对应章节停住。
5. 16帧为同一根部锚点、统一比例的真实透明素材，相邻帧短混合。不是CSS将最终图拉伸，也不是额外生成了几十张新姿态。各阶段时间详见 `garden-flower-lifecycle.md`。
6. 花走到目标姿态、人物动作完成后才登记为“已种植”。再次点已种植的花只走近、轻触并打开记录，不重复生长。
7. “重看这一章的生长”是独立重放入口，供旧存档体验；不重复写入种植或笔记。
8. 点人物可短暂转身回应；空闲只有轻微呼吸，不持续乱走。角色落点在花圈旁，不挡住花的主体。
9. 同章切换年龄只改变所看节点，不让角色反复走路。竖屏UI移到下方，人物附近仍有世界花朵。

### 记录与恢复

- “登记资料”：查看第二幕带来的五项原始答案，只读，不默默改现实年龄。
- 回溯目标不明确：保留“毕业前／2020年”等原话，只追问那时几岁，不凭当前年龄倒推出生年。
- “回到回溯起点”：回到确认的目标年龄；未知时打开确认框。
- “时间档案”：当前年龄专属文本记录；主动点“记录”才保存。当前是输入笔记，不是已经接通模型的问答。
- 记录按年龄保存，单条上限500字符，保留最近100条；同龄可多次记录，面板展示近期条目。
- R：在非输入、非面板阅读状态中取消未完成动作，人物停在当下位置；不会传送或清空老资料。屏幕上的R按钮也可关闭面板回到画面；键盘在阅读面板时先用Esc关闭。
- 输入框不抢W作为移动输入；打字时左右、R等不会误触主场景。
- 刷新花园恢复本机资料、已种选择、当前年龄和记录；未完成的种植不提交。重新走第二幕后资料改变会创建与新登记对应的花园，不混用上一份人生档案。存档键为 `life-backtest.garden.v2`。
- 种到现实年龄后进入月面三岔口：回溯／前进／前瞻／结束四颗像素小行星。点入后是裂隙页，不是整屏圆形卡片。内容为演示，事件 `life-backtest:garden-rift-open` 供队友接真实节点。Esc 在裂隙内先退一层，顶栏「返回三岔口」直接回岔路。

## 5. 美术、声音与呈现纪律

- 普通游戏场景统一黑白像素语言，保留现有玩家形象和月面构图。真实来源资料以后可使用克制现实呈现，但需有明确过渡。
- UI围绕玩家行为：悬停光环、种植过程、时间节点和来源阅读；不改成卡片墙、网站导航或AI聊天首页。
- 海岸与穿梭、登记、脚步、落种、完成由各自状态触发短音。生长不是每一帧播放一次声音。
- 页面隐藏、过场或阅读时按既定状态暂停；低动态偏好减轻剧烈运动。
- 音效触发时序已有代码/测试支持，但本轮交接不等同于完成了耳机和扬声器的主观混音验收。

## 8. 当前限制和不要误承诺的事

- 裂隙帖子可在本仓库独立调用知乎公开搜索；未配置 Access Secret 时回退演示帖。配置见 docs/ZHIHU_SETUP.md。仍无玩家 OAuth、真实人物匹配模型、联网对话或联系方式。
- 无可靠出生日期，因此当前UI不自动显示“22岁=2022年”。需补出生年／生日及不确定性规则才能支持。
- 本机存储不是跨设备账号；清理浏览器网站数据或更换域名／端口都会影响可见存档。
- 第二幕重置会清除本次登记；不是所有R都保留所有数据。
- 本次不改现行门效果或宣称恢复到此前所有参考图中的同一个90°状态。
- 第一幕核心图片加载失败的完整重试体验、WebGL上下文恢复、移动端帧率、线上慢网和主观音效仍需更广泛设备验收。
- 构建有约598KB主包体积提示；public保留概念参考图，当前便于交接而非极限下载优化。
- GitHub上传、开源授权、在线网站部署是不同动作；目前准备了仓库文件，不代表已经上传或上线。
