当前最重要的已确认状态：

- 完整流程是海岸回溯 → 月面档案局五问/审查/开门 → 月面人生花园 → 三岔口/平行宇宙访谈和结果。
- 第三幕花朵使用8种花×16帧透明像素图集；玩家选哪种，地面就必须长出完全相同的品种和颜色。绝对不要修改或替换花朵造型与颜色。
- 花朵采用两次点击：第一次确认选项并显示“再点击一次种下你的选择”，第二次才种植。

- 银河、基地、地表是三个独立遮罩系统。银河与绿色地表绝不能覆盖基地。
- 基地使用枪灰、钢蓝、银灰、铜色结构和琥珀暖灯；约60%后开始复色。
- 银河约80%后开始复色，最终为靛蓝、蓝紫、紫罗兰、少量洋红尘埃与银白核心，同时把蓝、紫、暖白和少量暖金星点分散到整个天空。
- 花朵颜色和形象已经得到用户确认；最新视觉证据在 `docs/reference/`。
- UI和重要文字保持暖白，不随环境染色；深空仍以黑色为主。
- 项目技术是Vite + TypeScript + Canvas/DOM，不是React或Phaser。
