# Past-Forward 换账号交接基线

交付日期：2026-09-14  
项目技术：TypeScript + Vite + Canvas/DOM + 少量 Three.js  
项目性质：在现有项目上持续迭代，不允许另起脱离原流程的演示页。

## 1. 新账号如何接手

1. 解压交接ZIP到一个纯英文或现有工作目录。
2. 在Codex中选择解压后的项目根目录；根目录必须能看到 `package.json`、`src`、`public`、`docs`。
3. 首先让新账号完整阅读：`AGENTS.md`、`README.md`、本文件、`docs/TEAM_HANDOFF.md`、`docs/INTEGRATION.md`。
4. 把 `docs/NEXT_ACCOUNT_PROMPT.md` 全文作为第一条消息发送给新账号。
5. 安装 Node.js 22.12以上和 pnpm 11.19，然后执行：

```powershell
pnpm install --frozen-lockfile
pnpm verify
pnpm dev --host 127.0.0.1 --port 4175
```

6. 打开 `http://127.0.0.1:4175/` 验证完整流程；第三幕续玩入口为 `http://127.0.0.1:4175/?scene=garden`，干净调试入口为 `/?debug=garden`。

Codex聊天记录不会因为复制项目文件而自动成为另一个账号的对话历史。本交接文档、代码、测试和参考图才是跨账号继续工作的基线。新账号不得凭记忆重建页面，应先检查现有实现。

## 2. 当前可玩流程

```text
第一幕：黑白海岸
  上滚/方向键靠近月球 → 拖动月球 → 开始回测
  → 回溯穿梭与白场

第二幕：月面档案局
  W/↑行走 → 回答五项登记 → 模拟人生审查
  → 门解锁并打开 → 玩家主动走入门 → 白场交接

第三幕：月面人生花园
  选择年龄 → 查看花朵选项 → 第一次点击确认选项
  → 显示“再点击一次种下你的选择” → 第二次点击
  → 人物快速走近 → 播种 → 同品种16帧生长 → 写入存档
  → 每株花恢复一块月壤生命色彩 → 按真实种植比例恢复环境
  → NPC/记录/下一年龄 → 种到现年后进入三岔口

第四幕：平行宇宙回溯
  三岔口进入回溯、前进、前瞻或结束分支
  → 平行宇宙时间线与访谈

第五幕：回测报告与推荐
  第四幕结束 → 人生回测报告主面板
  → 同代/前辈人物入口与个人标签
```

第五幕沿用现有三岔口结果流程和第四幕访谈存档，没有另建孤立演示页或复制业务状态。报告是主视觉；同代和前辈在右侧上下排列，真实公开头像可用时填充，缺失时显示明确占位。

## 3. 已确认且不能破坏的产品原则

- 不删除现有框架、内容和业务逻辑；避免无关重构。
- 交互必须轻量，不堆叠按钮、弹窗或多余动画。
- 数据允许使用演示数据，但获取路径必须在逻辑上讲得通，并明确标注演示、推断和真实来源。
- 花朵选项不是“手指指向某一朵”的单选暗示；所有可选花通过文字与顺序动效共同提示。
- 第一次点击花朵只确认；第二次点击才种下。
- 玩家选择什么花，地面必须长出同品种、同叶片和同现实颜色的花，不能替换为通用雏菊。
- 花朵资产、类型和颜色已经确认，后续视觉修改不得擅自改变。
- 复色按真实完成种植次数计算，不按固定花序伪造。
- UI保持暖白，不随环境染色；深空仍以黑色为主。

## 4. 第三幕当前视觉系统

### 4.1 花朵与速度

- 图集：`public/assets/garden/flower-lifecycle-kinds-v2.png`。
- 16列×8行，每格128×128；根部锚点 x=64、y=112。
- 八种花：白色雏菊、银灰刺冠花、蓝紫风铃花、灰紫松果菊、珊瑚红杯形花、淡蓝白莲形花、冰蓝星形花、暗红玫瑰。
- 每种花完整经过种子、破壳、发芽、长叶、长茎、花苞、展开、稳定盛放。
- 当前完整生长约1.45秒；种植行走速度260像素/秒。只加速种植流程，没有加速登船剧情。

### 4.2 地表生命力

- 每次完成一株花，只恢复该花附近一块不规则月壤。
- 花朵自己的色彩决定根部局部生命色；大范围地表使用低饱和苔藓绿、橄榄色、土黄、棕褐、锈橙和矿物青。
- 独立生长层会绘制苔藓簇、地衣点和贴地生命枝脉，不是整屏滤镜。
- 未种植节点保持灰暗种子或占位，不提前出现彩色花。

### 4.3 银河、地球和基地分阶段恢复

- 前几株花：银河、地球和基地保持黑白。
- 约60%：颜色先沿基地支脚进入；随后恢复坡道。
- 约80%：地球低饱和蓝绿和银河开始出现。
- 约84%以后：基地枪灰/钢蓝主体逐渐复色。
- 100%：银河呈靛蓝、蓝紫、紫罗兰、少量洋红尘埃与银白核心；天空其他区域有蓝、紫、暖白与少量暖金星点。
- 基地拥有独立轮廓遮罩和独立配色：枪灰、深钢灰、冷蓝灰、银灰高光、铜色结构和琥珀暖灯。
- 银河层和地表层在绘制后都会擦除基地轮廓，因此紫色、绿色不得覆盖基地。
- 银河和地表也分别受天空/月壤遮罩约束，不能穿过地球、基地或界面。
- 飞船进入太空航行和回溯入口后，月壤复色、苔藓、生命枝脉、地表轮廓光和旧基地灯层全部退出；只保留银河/星点及独立的彩色轨道飞船素材，地表生命层不能跟随飞船进入太空。

## 8. 新账号下一步工作方式

1. 每次先复现当前页面，再讨论要改哪一幕。
2. 一次只做一个阶段，完成后让用户在4175页面共同验收。
3. 视觉修改必须验证0%、第一株、约50%、约80%和100%五种状态。
4. 改第三幕时，确认花朵未变、基地无紫/绿串色、复色百分比仍由真实种植计算。
5. 改动后至少运行 `pnpm check`、`pnpm test`、`pnpm build`；涉及流程必须跑对应Playwright测试。
6. 不把参考图直接覆盖成背景来伪装实现。
