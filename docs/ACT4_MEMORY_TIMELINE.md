# 第四幕：回溯 / 逐次显影时间线

## 本轮范围

在现有第四幕实现时间线，不另建演示页面。左上角标题为“回溯”。第三幕花朵素材、造型、颜色未修改，第五幕未改版。后续对话与报告入口保留。

## 交互与数据

- 初始只显示“重大事件”起点和 0/N，不显示未来记录文字。
- 每次点击显影一条；显影中再点击只完成当前条。长按可连续回放，松手停止，完成后不自动进入对话。
- 按已确认回溯年龄、收集的重大事件、实际种植选择和当前年龄构建时间线；同年龄的事件先于选择。玩家修改过的同龄选择采用最终记录。
- 实际选择和既有理想分支数据分开传递，不把推演当成玩家经历。空数据不编造人生事件。
- 已显影节点可点开完整文字。长记录扩展为横向多段路径，自动跟随当前节点，支持触摸横向浏览；不靠缩小文字塞入一屏。
- 显影完成后点击“聆听另一个我的回应”进入原有对话。

## 文件

- `src/interview/memoryTimeline.ts`：事实映射、排序、布局。
- `src/interview/createInterviewScene.ts`：显影状态、长按、详情、对话衔接。
- `src/interview/interview.css`：布局、像素边框、动效、窄屏与减少动态效果。
- `src/garden/createGardenScene.ts`：向第四幕独立传递实际种植记录。
- `src/main.ts`：上下文传递及读取已有存档的 `?scene=interview` 入口。
- `public/assets/garden/rewind-cosmos-v1.png`：第四幕纯环境素材。
- `src/interview/memoryTimeline.test.ts`、`tests/memory-timeline.spec.ts`：数据与交互测试。

## 素材与实现

纯环境素材根据用户所选参考图生成，移除参考中的所有文字、云朵、连接线及 UI，保留彩色银河、地球、暖灯金属基地和灰色月面构图。它仅是背景；节点、内容、计数、连接线和按钮都是动态代码，不是整张参考图覆盖页面。

时间线节点使用像素矩形：短文字让矩形自然收窄，长文字在可用网格宽度内换行；不同内容类别仅通过冷青或暖金边框区分，不再使用云朵与爆炸形轮廓。全部节点通过单线或多层蛇形布局压入当前画面，不显示时间线滚动条。文字保持可访问、安全的纯文本，过长内容仍可点击查看全文。连接线按每个矩形的实际尺寸停在边缘，不穿过文字。动效使用有限时长 CSS 动画，减少动态效果偏好下取消动画。

## 验证与使用

`pnpm verify` 已通过类型检查、153 项单元测试、构建及发布检查；构建仍有既有主包超过 500 kB 的提示。

第四幕的两项浏览器测试覆盖：桌面 1672×941 的逐次显影/防提前泄露/详情/后续对话；390×844 窄屏的 21 条记录、长按停止、全节点视口内布局、无时间线滚动条和减少动态效果。测试使用隔离存储与模拟接口，不覆盖用户真实存档。

最终完整浏览器回归为 18 通过、3 失败；第四幕两项专项以及第三幕登船进入第四幕的衔接测试通过。失败发生在前序场景：

- `archive-door.spec.ts:76`：90 秒内未完成档案局门角度采样，等待场景元素超时。
- `flower-lifecycle.spec.ts:35`：测试期待 `is-planting` 类，实际花朵经过生长帧后已稳定盛放。
- `garden.spec.ts:228`：测试未捕获短暂的 `kneeling` 状态，最终采样为 `idle`。

本轮未修改这些前序动效与测试断言，不将失败断言简单删除来伪造全绿；这三项仍待专项排查，不能宣称全项目端到端测试全部通过。
