# 第五幕：回测报告主视觉

## 本轮范围

只修改第五幕结果页，不修改第四幕的时间线、对话匣、状态机或事件契约。第四幕结束后仍通过 `life-backtest:interview-done` 进入现有 `gardenScene.openOutlook()`，第五幕继续使用 `RiftView.kind = 'end'`，没有复制新的业务状态。

## 画面层级

- 人生回测报告位于左侧，占约 58% 画面宽度和 52% 画面高度，是唯一主面板。
- 报告本体也采用圆角半透明玻璃外框：细白高光边、背景模糊与暗色透明渐变和人物卡保持同一套材质语言。
- 报告头固定，正文独立滚动；正文分为「访谈回看」和「轨迹提炼」两列。
- 左侧「访谈回看」采用暖金色层级，未完成的节点明确显示“待回到第四幕继续核验”。
- 「同代」和「前辈」位于右侧上下排列，作为报告的辅助人物入口，不再与报告等宽并列。
- 两张人物卡使用高透明圆角玻璃材质，带细高光、背景模糊和胶囊链接；视觉质感参考手机界面，但保留本项目字体和深空语境。

## 个人展望聚焦态

- 第五幕的「写下个人展望」不再使用底栏内的小浮层，而是临时挂载到应用顶层，避开 `garden-frame` 与裂隙之间的堆叠上下文。
- 桌面端显示为右侧模态抽屉；打开时同代与前辈卡退场，人生报告留在暗幕下作为参考，不再发生玻璃文字透叠。
- 「未来打算」输入框位于首屏，个人信息与选择链默认折叠；保存、取消、关闭、暗幕和 Esc 共用同一关闭与焦点恢复逻辑。
- 720px 以下使用四边留安全间距的视口级面板，输入框与保存按钮不依赖被缩放的游戏底栏。
- 该变体只由第五幕结束页触发，第四幕继续使用原有个人标签交互。

## 知乎头像边界

- 每张人物卡保留一个大头像框。
- 真实知乎公开检索返回 `AuthorAvatar` 时，经过现有知乎域名白名单校验后填入头像框。
- 没有公开头像或图片加载失败时，只显示「知乎头像 / 待公开原文载入」占位，不生成或伪造真人头像。
- 推荐仍保留「不是匹配分数」「不会伪造真人原话」等来源说明。

## 实现与验证

- `src/garden/gardenRift.ts`：报告分栏、头像框、异步头像水合。
- `src/garden/garden.css`：报告主视觉、金色左栏、右侧玻璃人物卡。
- `src/outlook/createPersonalTag.ts`：第五幕顶层挂载、模态聚焦、上下文折叠与焦点恢复。
- `src/garden/riftContent.ts`、`src/zhihu/liveContent.ts`：将公开头像字段传到第五幕。
- `src/garden/gardenRift.test.ts`、`tests/garden.spec.ts`：验证两个头像框、占位状态、刷新后保留、报告面积显著大于单张人物卡，以及报告本体的圆角玻璃边框。

`pnpm verify` 已通过 29 个测试文件、153 项单元测试、生产构建和发布文件检查。构建仍保留既有的主包超过 500 kB 非阻断提示。
