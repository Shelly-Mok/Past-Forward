# 人生回测开场：场景合同

## A 帧：海边凝望

- 玩家意图：在安静的海岸中发现并靠近远处的月亮。
- 主要动作：向上滚动（inspect → approach）。
- 镜头变化：初始固定远景；滚轮输入后以月亮为锚点连续推进。
- 声音提示：本轮仍不加入；先单独验证滚轮与视觉转场。
- 人的证据：无；这里只建立玩家自己的当下。
- 退出状态：月球位于宇宙中央，等待下一阶段的拖拽交互。

## B 帧：靠近月亮

- 玩家意图：离开海岸，进入月亮所在的宇宙空间。
- 主要动作：持续向上滚动；向下滚动可以退回海岸。
- 镜头变化：月亮从右上方移动到画面中央并扩大；海岸沉入黑暗，星点从月亮周围向外显现。
- 距离节奏：前进总滚动距离约 1400 像素；0%–25% 缓慢启程，25%–70% 稳定靠近，70%–100% 加速脱离海岸。返回距离约 1050 像素。
- 声音提示：暂不实现；未来使用海浪低通与低频空间声确认越界。
- 人的证据：无；这是进入人生回测之前的第一道空间门槛。
- 退出状态：星空完全稳定，月球约占画面高度 40%。

## C 帧：未发生的人生经过

- 玩家意图：理解月球代表的不是答案，而是另一条未曾走过的人生。
- 主要动作：由“滚动靠近”触发；抵达宇宙后字幕自动播放，玩家无需继续滚动。
- 镜头变化：月球固定在宇宙中央；三组左右对照文字从底部进入、在月球两侧短暂停留并离开顶部。
- 声音提示：本轮不加入；未来使用三次极轻的低频记忆脉冲对应三组文字。
- 人的证据：无；此处只建立“已发生 / 未发生”的模拟边界，不冒充真实人物陈述。
- 退出状态：环形文字和“人生回测”留在月球上，月球等待后续拖拽交互。
- 返回行为：玩家向下滚动至宇宙阈值以下时，字幕立即退场并复位；再次抵达时重新播放。

## D 帧：移开月球，显露入口

- 玩家意图：亲手移开遮住入口的月球，找到人生回测的起点。
- 主要动作：按住月球，沿右下方向拖动并释放（hold → pull → release）。
- 镜头变化：镜头保持稳定；月球沿受约束的斜向轨道缩小并移向右下停泊点，左下至右上的宽阔银河随拖拽进度显露。
- 声音提示：抓住月球时使用一次低频锁定声；未完成时用更低的回弹声；成功吸附后使用短促、安静的确认声。
- 人的证据：无；入口仍属于玩家自己的模拟空间。
- 失败与恢复：在 78% 进度前松手，月球带重量感回到中央，银河退入黑暗，操作提示重新出现。
- 退出状态：月球固定于右下停泊点，银河完整显露，中央出现“人生回测 / 开始回测”，等待玩家主动进入。

## E 帧：穿过平行时间

- 玩家意图：确认离开当前时间，进入尚未发生的人生空间。
- 主要动作：点击“开始回测”（confirm）；随后进入约 6.2 秒的作者化转场，不要求玩家继续输入。
- 镜头变化：标题和按钮以阶梯节奏退场；月球在 1.35 秒内从右下带惯性回到中央；镜头随后以月球为锚沿 Z 轴持续推进。银河被放大并拉伸，远景星点、中景星尘和近景星轨以三种速度从中央流向边缘。
- 平行语法：3 秒附近，部分星流向左上和右下短暂分岔；低亮度灰阶残影延迟一至两帧；月球出现一次克制的双向轮廓回声，随后重新合一。平行宇宙不通过堆放多个行星表达。
- 穿越语法：4.12 秒后月球扩大并开始灰阶像素溶解；近景星轨达到速度峰值，随后快速抽离。三条微弱时间流最终收束为中央白点。
- 声音提示：按钮确认音 → 低频锁定 → 经过低通的颗粒空间风 → 峰值吸入 → 抵达前迅速归于安静。
- 人的证据：无；这里仍是从当前人生进入模拟空间的边界，不展示或伪造任何真实人物内容。
- 输入边界：穿梭期间滚轮、拖拽和按钮均锁定；页面失焦时冻结时间，返回后从原位置继续。
- 退出状态：中央白点稳定，触发 `life-backtest:warp-complete`，目标标记为 `time-ferry-station`，供下一场 NPC 信息收集场景接入。

## 视觉基准

- 唯一母版：`public/assets/opening-shore-master.png`。
- 比例固定为母版原始尺寸 1672:941；非同宽高比屏幕用纯黑留边，不裁切主体。
- 少年、孤船、月亮、浪线、山体、云层的位置不得凭感觉重画。
- 不出现标题、功能说明、HUD、卡片或常驻操作提示。
- 首次进入 1.4 秒后，只允许出现一次底部提示“向上滚动，靠近月亮”；开始滚动后立即退场。
- 只有月亮拥有极轻的悬停与点击反馈，为下一步交互埋点。

## 环境循环

- 海浪以 12 FPS 的阶梯节奏分四个深度带错位移动。
- 月光倒影独立于浪线闪烁，月亮本体不漂移、不旋转。
- 孤船上下不超过 2 个母版像素，横移不超过 1 个像素，倾斜不超过约 0.2°。
- 云层只在原构图附近往返 2 个母版像素。
- 少年作为观察者锚点完全静止。近岸浪带绘制后必须恢复人物原始像素，禁止头部、衣服或脚底继承海浪位移。
- 动画必须能在任意帧暂停后仍然保持图一的构图关系。

## 当前实现范围

`海边凝望 → 滚轮推进 → 月亮逐渐放大 → 海面与人物退出视野 → 进入星空 → 三组人生对照自动经过 → 拖动月球 → 银河显露 → 开始回测 → 月球归位 → 平行时间穿梭`
